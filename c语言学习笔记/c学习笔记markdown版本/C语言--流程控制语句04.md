### 1. `switch` 的“穿透”（冲撞感）

就像一颗子弹打进管道，或者像滑雪运动员从山顶冲下来。它**不思考、不犹豫**，从你指定的那个入口（`case`）扎进去之后，就一股脑地往下冲，直到撞上 `break` 这堵墙才停下来。**它的核心是“流向”**，一旦确定入口，后面全是机械式的执行。（离散）（常量）（效率）（简单）

### 2. `if` 的“犹豫”（审议感）

就像站在一个又一个的岔路口。每到一处，它都要**停下来想一想**（判断括号里的条件是真的还是假的）。如果第一条路不通，它站在那儿犹豫一下，再拐去问第二条路……**它的核心是“决策”**，每一次判断都是一次独立的逻辑权衡。（连续）（复杂）%%

```c
#include<stdio.h>
int main()
{
	printf("该工具可用于检测一个数是否为2的非负次幂\n请输入一个正整数\n");

	double num1;

	scanf("%lf", &num1);

	int num2 =(int)num1;

	int numa2 = num2;
	//提前定义一个整型变量，使得结果不会成2.000000这样
	double num3 = num1 - num2;
	/*相减取余一定是 double int double
	如果是int int double 会出现5/2=2d的情况*/
	if (num3 == 0&&num2>0)
		//提前排除小数和负数
	{
		if (num2 == 1)
		{
			printf("%d是2的幂次数\n", numa2);
		}
		else
		{
			double num6 = 0;
			double num7 = 0;
			/*先写一个常量使得第一次可以运行
			再通过改变常量的值num=num/2
			使得之后的循环可以结束*/
			while (num6 == 0 && (num7>1.000001||num7<0.999999))
				//非2次幂最好用区间形式表达
			{
				{
					num1 = num1 / 2;
					int num5 = (int)num1;
					num6 = num1 - num5;
					num7 = num1;
					//num7不能是int
					//这一步使得是1的情况会停止
					//第一次进入时num1没变，无需定义新变量
				}
			}
			if (num1 == 1)
			{
				printf("%d是2的幂次数\n", numa2);
			}
			else
			{
				printf("%d不是2的幂次数\n", numa2);
			}
	    }
	}
	else
	{
		printf("请输入一个正整数\n");
	}
	return 0;
}
```
