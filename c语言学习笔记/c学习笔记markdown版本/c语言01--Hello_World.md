[[C语言核心语法02]]


1.代码内容
```c
#include<stdio.h>

int main()
{
	printf("Hello World!");
	return 0;
}
```
2.分析
```text
·#include ==预处理==-><导出的位置，方式>
·int提示后面的结束指令提示为==整数==
·main()==主入口==的名字
·{}内容的==囊括==
·printf  要输出的内容 ==打印==
·()==输出语句==
·""==引用==，指定,不可少
·return  ==结束== 
·0  与前面的int呼应==整数==
·   ； 即==句号==

```
