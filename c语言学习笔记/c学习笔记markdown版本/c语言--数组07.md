==1.定义==
**数组:是一种容器,可以用来存储==同种数据类型==的多个值**
`（有隐式转换）`
==2.格式==
数据名称 数组名 【大小】
==3.数组的初始化==
初始化:定义数组的时候,**第一次给数组赋值**

int arr 【3】={1，2，3}

数据类型 数组名[长度]={数据值,数据值 ... }

`长度省略:数据值的个数就是数组长度
`长度未省略:数据值的个数 <= 长度`
`否则随机访问数据`
`未赋值的部分有默认值
`整数:0
`小数:0.0
`字符:'\0'
`字符串:NULL(什么都没有)`

==4.元素访问==
**·索引**
（从左到右0++进行标号）//【】**偏移量0为开始**
变量= 数组名[索引]

int num = arr[5]
**·修改**
数组名[索引]=数据值;

arr[5] =10;
==5.数组遍历==
遍历:依次获取数组中的每一个元素
**·已知长度可用循环**

```内存:软件在运行时,用来临时存储数据的 
内存地址：编号

64位：2⁶⁴--16进制

%p  &num查找数据位置
```
**一个索引（）个字节，从左到右累加进行**（）与数据类型有关
