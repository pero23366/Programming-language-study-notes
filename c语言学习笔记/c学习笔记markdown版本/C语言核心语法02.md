**7.常见的进制**
```text
·由二进制处理规定

000-0
111-7
十六进制：2⁴四个二进制一组
0000-0
1111-15

二进制:由0和1组成,代码中==以0b开头==
十进制:由0~9组成,前面==不加任何前缀==
八进制:由0~7组成,代码中==以0开头==
十六进制:由0~9还有a~f组成,代码中以==Ox开头==（a-10,b-11,c-12…
%%先看前缀，单个去读%%
·转换
1.任意进制转10进制
==公式:基数的权次幂×系数 相加==
系数:就是每一位上的数
基数:当前进制数
权:从右往左,依次为012345
2.2进制转10进制
8421
3.十进制转任意进制（除基商0余倒拼
不断的除以基数(==几进制,基数就是几==)得到余数==,直到商为0==,再将余数倒着拼起来即可。
例子：2进制  11/2=5……1
              5/2=2……1
              2/2=1……0
              1/2=0……1
```
