**4.隐式转换**（默认）
计算时,数据类型不一样不能直接运算,需要转成一样的,才能运算
==把一个取值范围小的,转成取值范围大的==
取值范围:
==char < short < int < long < long long < float < double==

什么时候转换?
不同的数据类型进行计算、赋值等操作,会触发隐式转换

转换规则1:
取值范围小的,和取值范围大的进行运算,小的会先提升为大的,再进行运算

转换规则2:
==char short类型的数据在运算的时候,都会直接先提升为int,然后再进行运算==
==5.强制转化==
如果把取值范围大的,赋值给取值范围小的,就需要进行强制转换

格式:目标数据类型 变量名=(目标数据类型)被强转的数据;

例：int b=10 ;
     short i=(short)b;
PS：1.对应的数据精度不能超过
     2.整体要整体（）起来
     `sizeof` **不会**因为赋值操作而改变对表达式的类型判断，它只看表达式本身的类型。赋值运算符右侧的表达式在编译时独立计算类型，然后才进行赋值转换，但 `sizeof` 不会“穿透”赋值去查看左侧变量的类型。`只会读，不会=`
==6.字符相加==
1.char short类型的数据在运算的时候,都会直接先提升为int,然后再进行运算
2.字母对应ASCALL码表，所以会升为int
printf("%d\n",'a');
printf("%d\n",'A');
printf("%d\n",'o');
`直接测`
- **`'a'`（单引号）**：
    
    - 在 C 语言中，它的==**类型是 `int`**（整数）==。
        
    - 编译时，编译器直接把它替换成对应的 ASCII 码数值（即 97）。
        
    - 所以 `printf("%d", 'a')` 等价于 `printf("%d", 97)`，打印结果完全正确。
        
- **`"a"`（双引号）**：
    
    - 它的==**类型是 `char*`**（字符指针）==，即一个指向内存地址的指针。
        
    - 它表示在内存中存储了字符 `'a'` 和末尾结束符 `'\0'` 的这块连续空间的**首地址**（比如 `0x7ffd1234`）。

==10.逻辑运算符==
作：连接多个表达式（∪）

| 符号   | 作用    | 说明                      |
| ---- | ----- | ----------------------- |
| &&   | 与（而且） | 两边都为真，结果才是真（有假就假）（同时满足） |
| \|\| | 或（或者） | 两边都为假，结果才是假（有真为真）（二选一）  |
| ！    | 非（取反） | 取反（！=）                  |
**用电路的思想：与是开关串联，或是开关并联，（1是闭合，0是断开）**
PS:短路效果
int a = 1, b = 5;
a >10 && ++b;
printf("x=%d, y=%d\n", a, b);
如果&&左侧已经不成立就不执行右侧的代码了-
