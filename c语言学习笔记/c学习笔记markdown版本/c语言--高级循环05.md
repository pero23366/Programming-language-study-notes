==1.无限循环==
```c
for ( ; ; )
{

}

printf("ß]geigei\n");

while (1)

printf("B]geigei\n");

}

do

{

}while (1);
```

**PS：1为成立无限循环**
**不要在无限循环下面写其他代码，不会运行**
==但是==无限循环内套入if等可以终止！！！

==2.跳转控制语句（break continue==
```c
break 结束接下来的整个循环
loop.c

for (int i = 1; i <= 5; i++)
{
if (i == 3)
{
break;
}

}
continue跳过特定循环

for (int i= 1; i <= 5; i++)
{
if (i == 3)
{
continue;
}
printf("%d\n",i);
}
```
==3.循环嵌套==
```c
for (int i = 0; i < 5; i++)
{
for (int j=0; j < 5; j++)
    {
    printf("aaa\n");
    }

}
```
**(分析内循环，外循环只是对内循环的重复)**
`PS：循环嵌套的跳出是对应的，内--内，外--外。
`或者给行标号，用goto a;(灵活)`
