### 1. 变量与声明方式（第 07、11、13 集）

**是什么**：JS 声明变量用三个关键字——`let`（块级、可改，默认用它）、`const`（块级、绑定不可改）、`var`（老写法，只作对比）。

**对标 C#**：`let x = 1` ≈ 局部变量；`const` ≈ `readonly`。

**差异（重点）**：

- **JS 没有类型声明。** 写的是 `let x = 1`，不是 `int x = 1`；而且变量可以**中途换类型** —— `x = 'hello'` 完全合法。C# 强类型，这一步编译就过不去。
- **`var` 与 `let` 的作用域不同。** `var` 是**函数作用域**且会**提升**，`let` 是**块级作用域**。C# 里所有变量都是块级，所以这个差异会让你**以为代码该报错却没报错**。
- **`const` 锁的是"绑定"，不是"内容"。** `const obj = {}` 之后 `obj.a = 1` 完全合法 —— 不许改的是"obj 这个名字指向谁"，不是它指向的东西。这一点和 `readonly` 的直觉基本一致，但很多人会误以为 const 对象是冻结的。

### 2. 数据类型（第 14、15、16、17 集）

**是什么**：JS 的基础类型只有 `Number`、`String`、`Boolean`、`null`、`undefined`（外加对象/数组/函数）。

**对标 C#**：`Number` ≈ 数字；`String` ≈ `string`；`Boolean` ≈ `bool`。

**差异（重点，全是坑）**：

- **只有一种数字类型。** 没有 int / double / float 之分，统统是 `Number`。由此带来三件事：
  - `0.1 + 0.2 !== 0.3`（浮点误差，C# 里 double 也一样，但 JS 没有 decimal 兜底）；
  - 除法永不出错，`1 / 0` 得 `Infinity`（C# 的 `int` 除以 0 直接抛异常）；
  - 有个专属值 `NaN`（Not a Number），而且 `NaN === NaN` 是 `false`。
- **字符串单双引号等价**，`'a'` 和 `"a"` 是同一个东西（C# 单引号是 char）。
- **模板字符串**：`` `文本${变量}` `` 对标 C# 的 `$"文本{变量}"` —— **几乎是同一个东西**，这一集 3 分钟过。
- **JS 有两个"空"**：`null`（人为置空）和 `undefined`（没赋值/不存在）。C# 只有一个 `null` + `Nullable<T>`。
- **`typeof` 对标 `GetType()`，但粗糙且有历史坑**：`typeof null === 'object'`（这是个一直没修的 bug）。

### 3. 类型转换（第 18 集）

**是什么**：分隐式转换（JS 自动做）和显式转换（你手动转）。

**对标 C#**：`Number()` / `parseInt()` ≈ `int.Parse` / `Convert.ToInt32`。

**差异（重点，万坑之源）**：

- **运算符决定转换方向**：`+` 偏字符串（做拼接），其余运算符偏数字（做运算）。
  - `'1' + 1` → `'11'`
  - `'3' - 1` → `2`
  - 同样是字符串配数字，结果一个是拼接一个是运算 —— **这是 JS 最经典的坑**。
- **转换失败不抛异常，给 `NaN`**。C# 的 `int.Parse("abc")` 直接 `FormatException`，JS 的 `Number('abc')` 安静地给你 `NaN`，错误被推迟到很久以后才炸。

### 4. 运算符与真假值（第 22、23、61、62 集）

**是什么**：赋值 / 自增 / 比较 / 逻辑 / 三元，和 C# 大体同名同义。

**差异（重点）**：

- **比较运算符 JS 独有**：`==` 宽松（会偷偷转类型）、`===` 严格（推荐，永远用它）。C# 只有 `==` 且类型不符直接编译不过；JS 里 `'1' == 1` 是 `true`。
- **逻辑运算符返回的不是布尔值**。C# 的 `&&` `||` 只产出 bool；JS 的**短路返回的是"原值"**：`0 || 'x'` 得 `'x'`，`'a' && 'b'` 得 `'b'`。常用来取默认值和做短路执行 —— **这个直觉千万别从 C# 迁移过来**。
- **假值表**（JS 独有）：只有 `false / 0 / '' / null / undefined / NaN` 六个是假，**其余全部为真，包括 `[]` 和 `{}`**。C# 里只有 `bool` 能进条件，没这套。
- **`switch` 内部用严格比较（`===`）**，且 `case` 不写 `break` 会穿透（这点和 C# 一样）。

### 5. 数组（第 12、36、41、43、44、46 集）

**是什么**：JS 数组是**万能动态容器**——长度可变、类型可混。

**对标 C#**：**对标 `List<object>`，不是 `int[]`**。

**差异（重点）**：

- `[1, 'a', true, {}]` 合法，一个数组里什么都能塞，长度随时变。
- **`arr.length` 是属性，不是方法**（对标 C# 的 `Length` / `Count`）。
- **反直觉：`arr[99] = 1` 不会报错**，会直接把数组撑到 100 长度、中间塞满 `undefined`。C# 数组越界直接抛 `IndexOutOfRangeException`。
- 增删方法：`push` / `unshift` 对标 `List<T>.Add` / `Insert`；`pop` / `shift` / `splice` 对标 `RemoveAt`。其中 **`splice` 最灵活也最容易用错**（增删改一把抓）。
- C# 侧你会顺手用 LINQ `Max()`，这里**故意手写循环** —— 因为数组高阶方法要到进阶篇才解锁。

---

### 6. 函数与作用域（第 49-62 集）

**是什么**：`function` 声明函数；函数是一等公民，可以赋值给变量、当参数传。

**对标 C#**：函数 ≈ 方法；**回调函数 ≈ `Action` / `Func<>` 委托**（你已学委托，直接对上）；函数表达式 ≈ 委托变量。

**差异（重点）**：

- **写法少了返回类型和参数类型**，逻辑与 C# 方法一致。
- **不校验参数个数**：传少了不报错，缺的参数是 `undefined`（C# 直接编译不过）。
- **不写 `return` 时函数返回 `undefined`**。C# 的 `void` 是"不产生值"，不是"产生一个空值" —— 这两个概念在 JS 里被合并了。
- **作用域有三种**：全局 / 函数 / 块级。⚠️ **顶层变量默认挂在 `window` 上**（隐式全局），C# 没有这种"默认全局"。
- **变量的访问原则 = 作用域链**（第 57 集给初步模型，第 152 集深讲）：从内往外一层层找。
- **匿名函数之函数表达式**：`let fn = function () {}` —— 这就是"函数是一等公民"的落地。⚠️ 本课程讲的是 `function () {}` 写法，**箭头函数留到第 157 集，现在不用**。
- **立即执行函数 IIFE**：`(function () {})()` —— **C# 无对应**。用途是造一个用完就销毁的私有作用域，避免污染全局。

---

### 7. 对象与内置对象（第 64-68、70、71 集）

**是什么**：对象字面量 `{ key: value }`；对象里存函数就是方法；内置对象先学 `Math`。

**对标 C#**：对象字面量像匿名对象 `new { }`，**但更像 `Dictionary`** —— 因为它能动态加字段。`Math` ≈ C# 的 `Math` 静态类（几乎同名同义）。

**差异（重点）**：

- **运行时可动态增删属性**：`obj.newKey = 1`、`delete obj.key` 都合法。C# 对象的成员编译期就固定了，**这是两种类型系统的根本差别**。
- **查属性有两种写法**：`obj.key` 与 `obj['key']`，后者能接**动态键名**（对标字典索引器）。
- **`for...in` 遍历对象** ≈ C# 遍历字典 / 反射取属性。
- **`Math.random()` 返回 0~1 的小数**；C# 是 `Random` **实例** + `Next()` —— 用法不同，目的相同。

---

### 8. 简单类型与引用类型（第 76 集）

**是什么**：变量到底存"值"还是存"地址"。

**对标 C#**：值类型 / 引用类型 —— **概念直接通**，栈/堆那一套你已经很熟。

**差异（重点）**：

- **JS 里只有「对象 / 数组 / 函数」是引用**，其余（**包括字符串**）都是值类型。
- ⚠️ 反直觉的一点：**C# 的 `string` 是引用类型**（只是不可变，表现得像值），**JS 的字符串是货真价实的值类型**。
- 这一集是第 187-190 集**深浅拷贝**的地基，现在先把"引用共享"这件事摆正。

==二：格式==

**变量声明：**

```js
let 名 = 值;        // 块级，可改（默认用它）
const 名 = 值;      // 块级，绑定不可改
var 名 = 值;        // 函数作用域 + 提升（老写法，只作对比）
```

**数据类型字面量：**

```js
Number    1 / 3.14 / Infinity / NaN
String    'abc' / "abc" / `abc`
Boolean   true / false
空        null / undefined
数组      [1, 'a', true]
对象      { key: value }
```

**模板字符串：**

```js
`文本${变量}文本`        // 对标 C# 的 $"文本{变量}"
```

**运算符：**

```js
===  !==                 // 严格，推荐
==   !=                  // 宽松，会转类型，少用
+ - * / %                // / 不会报错，除以 0 得 Infinity
&& || !                  // 短路返回原值，不是 bool
```

**分支：**

```js
if (条件) { } else { }
switch (值) { case 值1: …; break; default: … }   // 内部用 === 比较
```

**循环：**

```js
for (let i = 0; i < n; i++) { }
while (条件) { }
for (let i = 0; i < arr.length; i++) { }   // 遍历数组
for (let k in obj) { }                     // 遍历对象（键）
break; continue;                           // 同 C#
```

**数组常用：**

```js
arr.length                     // 属性，不是方法
arr.push(x)   arr.unshift(x)   // 尾 / 头 添加
arr.pop()     arr.shift()      // 尾 / 头 删除
arr.splice(起点, 个数, 新元素…)  // 万能增删改
```

**函数：**

```js
function 名(参数) { return 值; }      // 声明式
let 名 = function (参数) { };         // 函数表达式（匿名函数）
(function () { })();                  // IIFE，立即执行
// 参数未传 → undefined；不写 return → 返回 undefined
```

**对象：**

```js
let o = { key: 值, key2: 值2 };
o.key        o['key']        // 读（方括号可接动态键名）
o.key = 值                   // 增 / 改
delete o.key                 // 删
o.key = function () { };     // 存函数 = 方法
```

**内置对象：**

```js
Math.max(x, y)  Math.min(x, y)  Math.floor(x)  Math.ceil(x)
Math.round(x)   Math.abs(x)     Math.random()   // 0 ~ 1 的小数
```

==三：代码==

### 类型与转换的坑（第 07、14、17、18 集）

```js
let a = 1;              // 不需要写类型
a = 'hello';            // 中途换类型，完全合法（C# 编译不过）
console.log(typeof a);        // string
console.log(typeof null);     // object  ← 历史坑

console.log(0.1 + 0.2);       // 0.30000000000000004
console.log(1 / 0);           // Infinity
console.log('1' + 1);         // '11'  ← + 偏字符串，做拼接
console.log('3' - 1);         // 2     ← 其他运算符偏数字，做运算
console.log(Number('abc'));   // NaN   ← 不抛异常
console.log(parseInt('12px'));// 12
```

**你要观察**：同样是字符串配数字，`-` 出数字、`+` 出字符串；转换失败**不报错**，只给 `NaN`。

### 比较与真假值（第 22、61、62 集）

```js
console.log('1' == 1);        // true   ← 宽松，偷偷转类型
console.log('1' === 1);       // false  ← 严格，永远用它

console.log(Boolean([]));     // true   ← 空数组也是真
console.log(Boolean(0));      // false
console.log(Boolean(''));     // false

let n = 0;
console.log(n || 10);         // 10     ← 短路返回"原值"，常用来取默认值
console.log('a' && 'b');      // 'b'
```

### 数组：动态容器（第 12、43、44、46 集）

```js
let arr = [1, 'a', true];     // 类型可混、长度可变
arr[99] = 1;                  // 不报错！直接撑到 100 长，中间全是 undefined
console.log(arr.length);      // 100

arr.push('尾巴');             // 尾部加（对标 List.Add）
arr.unshift('头');            // 头部加（对标 List.Insert(0, x)）
arr.pop();                    // 删尾（对标 RemoveAt(Count-1)）
arr.shift();                  // 删头（对标 RemoveAt(0)）
```

### 函数：一等公民（第 49、50、53、58、59 集）

```js
function sum(a, b) {
    return a + b;
}
console.log(sum(1, 2));       // 3
console.log(sum(1));          // NaN —— 参数少了不报错，b 是 undefined

function log(msg) {
    console.log(msg);
}
log('hi');                    // 打印 hi
console.log(log('hi2'));      // 先打印 hi2，再打印 undefined（没写 return）

let fn = function (x) { return x * 2; };   // 函数表达式
console.log(fn(3));           // 6

(function () {                // IIFE：造一个用完就走的私有作用域
    let secret = '只活在这一刻';
    console.log(secret);
})();
```

### 对象：可动态增删（第 64、65、66、67、68 集）

```js
let stu = { name: '小王', age: 18 };   // 对象字面量
stu.score = 90;               // 运行时动态加属性（C# 做不到）
delete stu.age;               // 动态删属性

console.log(stu.name);        // 小王
let key = 'score';
console.log(stu[key]);        // 90 —— 方括号能接动态键名

stu.say = function () {       // 对象里存函数 = 方法
    console.log('我是' + stu.name);   // 这里先用 stu.name；this 第 67 集埋线、第 102 集正式讲
};
stu.say();

for (let k in stu) {          // 遍历对象
    console.log(k, stu[k]);
}
```

### 内置对象 Math（第 70、71 集）

```js
console.log(Math.max(1, 5, 3));   // 5
console.log(Math.floor(3.9));     // 3
console.log(Math.random());       // 0 ~ 1 的小数（不用 new，对标 Random 实例的 Next()）
let n = Math.floor(Math.random() * 10) + 1;   // 1~10 的整数
```

### 值类型 / 引用类型（第 76 集）

```js
let a = 1;
let b = a;
b = 99;
console.log(a);          // 1  —— 值类型，各存各的

let o1 = { x: 1 };
let o2 = o1;             // 只是把"地址"复制了一份
o2.x = 99;
console.log(o1.x);       // 99 —— 引用类型，改的是同一个对象

let s1 = 'abc';
let s2 = s1;
s2 = 'xyz';
console.log(s1);         // abc —— JS 的字符串是值类型（⚠️ C# 的 string 是引用类型）
```

### 5. 最容易被 C# 直觉带偏的 8 个坑（优先级从高到低）

| # | 坑 | 正确认知 |
|---|---|---|
| 1 | `+` 以为一定是加法 | `+` 偏字符串拼接，`-` 才偏数字运算 |
| 2 | 以为 `==` 和 C# 一样 | JS 用 `===`；`==` 会转类型 |
| 3 | 以为 `&&` `\|\|` 返回 bool | 短路返回**原值**，常用来取默认值 |
| 4 | 以为只有 `null` 一个空 | 还有 `undefined`；`typeof null === 'object'` |
| 5 | 以为数组越界会报错 | `arr[99] = 1` 直接把数组撑长 |
| 6 | 以为类型不匹配会报错 | 变量可换类型、参数可少传、转换失败给 `NaN` |
| 7 | 以为 `const` 对象不可改 | 锁的是**绑定**，不是内容 |
| 8 | 以为字符串是引用类型 | JS 里字符串是**值类型**（只有对象/数组/函数是引用） |
