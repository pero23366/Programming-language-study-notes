==一：概念==
**字体图标（iconfont）**，它能让你在网页里用上任意缩放、颜色可控的矢量小图标，比如购物车、搜索、用户头像等。
### 为什么用字体图标，而不是图片？

以前网页里的图标都是图片（PNG/SVG），但图片图标有很多缺点：放大后会模糊、颜色固定、加载多个图片还会拖慢网页速度。

**字体图标**是把图标做成了“字体”里的一个“字”。你可以像设置文字一样，用 `color` 改颜色，用 `font-size` 改大小，而且**怎么放大都不会模糊**。阿里巴巴的 **iconfont** 是目前国内最主流的矢量图标库。
==二：格式==
### 三种引入方式与核心语法

从 iconfont 下载图标后，通常有三种使用方式，推荐优先掌握 **Font class** 方式。

**1. Font class（最推荐，语义化好，易维护）**

- **引入**：在 HTML 的 `<head>` 中引入下载包里的 `iconfont.css`。
    
- **使用**：`<i class="iconfont icon-图标名"></i>`，然后就可以像设置文字一样用 CSS 控制它的大小和颜色。
    

**2. Unicode（兼容性最强）**

- **引入**：在 CSS 中通过 `@font-face` 声明字体，并定义 `.iconfont` 类。
    
- **使用**：`<i class="iconfont">&#xe600;</i>`（`&#xe600;` 是图标对应的编码）。
    

**3. Symbol（支持彩色图标）**

- **引入**：引入下载包里的 `iconfont.js`。
    
- **使用**：`<svg class="icon"><use xlink:href="#icon-图标名"></use></svg>`
==三：代码==
**第1步：下载图标**

1. 打开 [iconfont.cn](http://iconfont.cn/)，登录。
    
2. 搜索并选中需要的图标，加入购物车。
    
3. 将购物车里的图标**添加至项目**。
    
4. 进入项目，点击 **“下载至本地”**，解压得到 `iconfont.css` 等文件。
    

**第2步：在 HTML 中引入**  
把解压出来的 `iconfont.css` 放到你的 `CSS` 文件夹里，然后在 HTML 的 `<head>` 中引入：

```html

<link rel="stylesheet" href="../CSS/iconfont.css">
```

**第3步：在 HTML 中使用**

```html

<!-- 搜索图标 -->
<i class="iconfont icon-sousuo"></i>
<!-- 购物车图标 -->
```
<i class="iconfont icon-gouwuche"></i>

**第4步：用 CSS 控制图标样式**

```css

/* 字体图标本质上就是文字，可以直接用字体相关的属性 */
.iconfont {
    font-size: 30px;      /* 控制大小 */
    color: #ff5000;       /* 控制颜色 */
}
```
==四：总结==
- **优势**：矢量缩放不模糊、可用 CSS 自由改色改大小、多个图标合并为一个字体文件，加载更快。
    
- **核心步骤**：iconfont 官网选图标 → 加入项目 → 下载到本地 → 引入 CSS → 用 `<i class="iconfont icon-名字"></i>` 使用。
    
- **推荐方式**：日常开发优先用 **Font class**，语义清晰，维护方便；如果项目需要**彩色图标**，再考虑 **Symbol** 方式。
    
- **一个小技巧**：如果只想用某个图标，又不想引入整个字体库，可以先用 Font class 跑通流程，后续再根据项目需要精简。
