**概念**：HTML 元素分为 **块级元素** 和 **内联元素**。块级元素独占一行，内联元素可以一行多个。[](https://www.bilibili.com/opus/1198084636212723721?from=search#1)

**格式**：

- 块级元素：`<div>`、`<p>`、`<h1>` 等，可以嵌套其他元素。
    
- 内联元素：`<span>`、`<a>`、`<strong>` 等，通常只包裹内容的一部分。
    

**代码**：

```html

<div>我是块级元素，独占一行</div>
<span>我是内联元素</span><span>我可以和你并排</span>
```

**总结**：分类决定了展示形式，但后面可以通过 CSS 的 `display` 属性改变。
