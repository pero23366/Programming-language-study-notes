**概念**：`<table>` 创建表格，`<tr>` 是行，`<td>` 是单元格，`<th>` 是表头。[](https://www.bilibili.com/opus/1198084636212723721?from=search#1)

**格式**：

- `<table>` > `<tr>` > `<td>` / `<th>`
    
- 合并单元格：`colspan`（跨列）、`rowspan`（跨行）。
    

**代码**：

```html

<table>
    <tr>
        <th>姓名</th>
        <th>年龄</th>
    </tr>
    <tr>
        <td>小明</td>
        <td>18</td>
    </tr>
</table>
```

**总结**：表格用于展示数据，美化表格是 CSS 的工作
