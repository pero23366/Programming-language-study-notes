==一：概念==
**NuGet 是什么？**  
NuGet 是 .NET 生态系统的**包管理器**，也是开发人员用来发现并获取 .NET 开源库的主要方式。它本质上是一个 Visual Studio 扩展，能够简化在项目中添加、更新和删除第三方库的操作。

**NuGet 包是什么？**  
NuGet 包（`*.nupkg`）实际上是一个 **ZIP 文件**，其中包含 .NET 程序集（DLL）以及相关的元数据（如版本号、依赖项等）。

**为什么需要 NuGet？**  
在 NuGet 出现之前，引用第三方库需要手动下载 DLL 文件，再复制到项目中并手动添加引用，过程繁琐且容易出错。NuGet 把这一过程自动化，让开发者可以像“安装 App”一样在项目中引入功能库。

**[NuGet.org](https://nuget.org/)**  
[NuGet.org](https://nuget.org/) 是微软提供的免费公共包托管服务，是获取绝大多数公开 NuGet 包的主要来源。此外，公司内部也可以搭建私有的 NuGet 服务器，仅供内部使用[](https://www.e-com-net.com/article/1744650216327364608.htm#1)。
