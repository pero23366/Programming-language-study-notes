# SQL 通用语法与分类

> 来源：P5《05. 基础-SQL-通用语法及分类》 · 档位 B 部分重叠
> 与我已知的关系：DDL/DML/DQL/DCL 这套分类和 T-SQL 一样，差别全在书写规范和注释符

==一：意义与概念==

SQL 是关系型数据库的**标准语言**，各家产品各说一种方言：SQL Server 说 T-SQL，Oracle 说 PL/SQL，MySQL 说 MySQL SQL。方言之间 90% 相同，剩下 10% 就是这门课要记的。

按作用分四类，和你写 T-SQL 时的分类完全一致：

| 分类 | 全称 | 管什么 | 典型语句 | 你的对应物 |
|---|---|---|---|---|
| DDL | Data Definition | 库、表、列、索引的结构 | `CREATE` `ALTER` `DROP` | 同 |
| DML | Data Manipulation | 表里的**行** | `INSERT` `UPDATE` `DELETE` | 同 |
| DQL | Data Query | 查 | `SELECT` | 同（T-SQL 里常并进 DML）|
| DCL | Data Control | 用户与权限 | `GRANT` `REVOKE` | 同 |

注意 MySQL 官方把 `SELECT` 单列成 DQL，T-SQL 教材一般算作 DML 的一部分——只是叫法不同，不影响写代码。

**三个真正的差异点**（这是本篇唯一值得记的东西）：

1. **注释符**：`-- 注释` 两个短横后**必须跟一个空格**，`--注释` 直接报错。T-SQL 里没有这个限制。另有 MySQL 独有的 `# 注释`。
2. **表名大小写**：Linux 上 `lower_case_table_names=0`，`User` 和 `user` 是两张表；Windows 上默认不敏感。**本地写通的 SQL 上服务器报"表不存在"，八成是这个。**
3. **字符串用单引号**：MySQL 单双引号都能包字符串，但双引号在 `ANSI_QUOTES` 模式下被当标识符，别养成双引号习惯。

==二：使用格式==

```sql
-- 单行注释（短横后必须空格）
# 单行注释（MySQL 独有）
/* 多行
   注释 */
SELECT id, name FROM user;   -- 分号结尾，可跨多行、可任意缩进
```

==四：总结归纳==

- 分类照 T-SQL 记，不用重学；把注意力放在注释符、大小写、引号三件事上。
- 记忆锚：MySQL 是"说方言的 SQL Server"，词一样、口音不同。
- 自测：① `--注释`（无空格）能执行吗？② 为什么同一句 SQL 在 Windows 能跑、部署到 Linux 报 1146 错误？
