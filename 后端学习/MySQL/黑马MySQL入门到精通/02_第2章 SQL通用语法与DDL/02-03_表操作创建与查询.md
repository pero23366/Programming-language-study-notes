# 表操作：创建与查询

> 来源：P7《07. 基础-SQL-DDL-表操作-创建&查询》 · 档位 A 几乎重叠
> 与我已知的关系：`CREATE TABLE` 骨架与 T-SQL 逐字一致，只多三个可选项

==一：意义与概念==

建表语句的骨架和 T-SQL 完全一样：列名 + 类型 + 约束，逗号分隔。差异只有三处，记住就能直接写：

1. **自增**：`id INT AUTO_INCREMENT PRIMARY KEY`，不是 `IDENTITY(1,1)`。且 `AUTO_INCREMENT` 的列**必须是主键或唯一键**。
2. **表尾可加引擎与字符集**：`ENGINE=InnoDB DEFAULT CHARSET=utf8mb4`。T-SQL 没这层，是 MySQL 独有的"表可选存储引擎"（第 10 章展开）。
3. **标识符用反引号**：`` `order` ``（`order` 是关键字，必须转义）。T-SQL 用 `[order]`。

查看表结构与 T-SQL 的差别：MySQL 用 `DESC` / `SHOW CREATE TABLE`，不是 SSMS 的图形界面。

==二：使用格式==

```sql
SHOW TABLES;                 -- 列当前库所有表
DESC 表名;                    -- 列结构：字段/类型/是否NULL/键/默认值/额外
SHOW CREATE TABLE 表名;       -- 看完整建表语句（含引擎、字符集）
DROP TABLE [IF EXISTS] 表名;
```

==四：总结归纳==

- 骨架照 T-SQL 写，改三处：`AUTO_INCREMENT`、`ENGINE=InnoDB`、反引号。
- 记忆锚：`DESC` 就是 SSMS 里那个"设计"窗口的文字版。
- 自测：`AUTO_INCREMENT` 能不配主键单独用吗？（不能）
