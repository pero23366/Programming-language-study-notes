# 循环：WHILE、REPEAT、LOOP

> 来源：P110–P112《53–55. 进阶-存储过程-循环-while / repeat / loop》 · 档位 C 全新
> 与我已知的关系：C# 有 `while`、`do-while`、`for`；MySQL **把 for 换成 LOOP + LEAVE**，没有 for

==一：意义与概念==

三种循环，对应你熟悉的三件事：

| MySQL | 形式 | C# 对应 | 特点 |
|---|---|---|---|
| `WHILE` | 先判断后执行 | `while` | 最少执行 0 次 |
| `REPEAT` | 先执行后判断 | `do-while` | **最少执行 1 次** |
| `LOOP` | 无限循环，靠 `LEAVE` 跳出 | `for(;;)` + `break` | 灵活，可实现 for |

**语法外壳差异（这才是真正要记的）**：

```sql
-- WHILE：END WHILE 收尾，DO 开头
WHILE 条件 DO
  语句;
END WHILE;

-- REPEAT：UNTIL 结尾（注意 UNTIL 在循环体之后）
REPEAT
  语句;
UNTIL 条件 END REPEAT;        -- 条件为真时退出（和 while 相反！）

-- LOOP：必须有 LEAVE 才能出
标号: LOOP
  语句;
  IF 条件 THEN LEAVE 标号; END IF;
END LOOP 标号;
```

两个反直觉点：

1. **`REPEAT ... UNTIL 条件` 的条件是"退出条件"**，而 `WHILE 条件` 是"继续条件"。写反了就是死循环或一次都不执行。
2. **`LOOP` 必须配标号 + `LEAVE`**，否则永远出不来。`ITERATE` 相当于 `continue`（跳过本次），`LEAVE` 相当于 `break`。

**没有 `FOR` 循环**：MySQL 要用 `LOOP` 手动维护计数器。这就是为什么存储过程里的循环代码看起来比 C# 啰嗦。

**性能警告（重要）**：**存储过程里的循环是逐行处理，性能极差**。插入 10 万行数据用循环 = 10 万次单行 INSERT。正确做法是用 `INSERT ... SELECT` 一条 SQL 搞定。循环只适合"确实需要逐行不同逻辑"的场景（比如按行调用另一个过程）。

和 EF Core 的关系：这对应"循环里发 SQL"的反模式。C# 里也常见：

```csharp
foreach (var item in list) { db.Add(item); db.SaveChanges(); }   // 10 万次往返
// 改成
db.AddRange(list); db.SaveChanges();
```

**"循环 + 单条 SQL"在任何语言、任何层都是性能杀手**，这是同一个道理。

==二：使用格式==

```sql
-- WHILE
DECLARE i INT DEFAULT 1;
WHILE i <= 10 DO
  INSERT INTO t VALUES (i);
  SET i = i + 1;
END WHILE;

-- REPEAT
DECLARE j INT DEFAULT 1;
REPEAT
  INSERT INTO t VALUES (j);
  SET j = j + 1;
UNTIL j > 10 END REPEAT;

-- LOOP
DECLARE k INT DEFAULT 1;
my_loop: LOOP
  INSERT INTO t VALUES (k);
  SET k = k + 1;
  IF k > 10 THEN LEAVE my_loop; END IF;
END LOOP my_loop;
```

==三：代码实践==

```sql
DELIMITER $$
CREATE PROCEDURE p_insert_n(IN n INT)
BEGIN
  DECLARE i INT DEFAULT 1;
  WHILE i <= n DO
    INSERT INTO t_demo (id) VALUES (i);
    SET i = i + 1;
  END WHILE;
END $$
DELIMITER ;

CALL p_insert_n(1000);     -- 1000 次单行插入，慢

-- 对比：一条 SQL 搞定（快几十倍）
INSERT INTO t_demo (id)
SELECT n FROM (WITH RECURSIVE seq(n) AS (
  SELECT 1 UNION ALL SELECT n+1 FROM seq WHERE n < 1000
) SELECT n FROM seq) x;
```

> 💡 延伸：`ITERATE` 相当于 `continue`，`LEAVE` 相当于 `break`，都要带标号。标号名随便起，但 `END LOOP 标号` 必须一致。

==四：总结归纳==

- 三条：`WHILE` 条件为真继续、`REPEAT ... UNTIL` 条件为真退出（相反）；`LOOP` 必须 `LEAVE`；循环逐行处理性能差，优先用 `INSERT ... SELECT`。
- 记忆锚：`REPEAT` 是"先做再问"，`WHILE` 是"先问再做"，`LOOP` 是"闷头做，靠 `LEAVE` 喊停"。
