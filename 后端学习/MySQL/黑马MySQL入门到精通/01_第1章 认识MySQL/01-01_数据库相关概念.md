# 数据库相关概念

> 来源：P2《02. 基础-课程内容-数据库相关概念》 · 档位 A 几乎重叠
> 与我已知的关系：库/表/行这套模型和 SQL Server 完全一致，换的只是产品名

==一：意义与概念==

四个词各指一层，别混：

| 名词 | 是什么 | 在你这儿的对应物 |
|---|---|---|
| 数据 | 被存下来的事实 | 实体对象里的属性值 |
| 数据库（DB） | 按结构组织的存储仓库 | 一个 `Database` |
| DBMS | 管理数据库的软件，**MySQL 就是它** | SQL Server 这个产品 |
| SQL | 操作 DBMS 的语言 | 同一套，方言不同 |

差别只有一层认知：SQL Server 时代 SSMS 和引擎常一起装，容易让人以为"SSMS 就是数据库"；MySQL 里 DBMS 是后台服务 `mysqld`，客户端（命令行、DataGrip）是另一个程序，**服务不开，客户端连不上**。

常见误解：把"MySQL"叫成数据库。严格说它是一套 DBMS，你 `CREATE DATABASE test` 建出来的 `test` 才是数据库。

==四：总结归纳==

- 数据 → 数据库存 → DBMS 管 → SQL 用，四层各司其职。
- 记忆锚：数据库是仓库，DBMS 是仓库管理员，SQL 是你对管理员说的话。
