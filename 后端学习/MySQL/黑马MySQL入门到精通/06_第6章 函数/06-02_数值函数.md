# 数值函数

> 来源：P28《28. 基础-函数-数值函数》 · 档位 A 几乎重叠
> 与我已知的关系：`CEIL` / `FLOOR` / `ROUND` / `MOD` 语义与 T-SQL 完全一致

==一：意义与概念==

五个函数，闭着眼能用：

| 需求 | MySQL | T-SQL |
|---|---|---|
| 向上取整 | `CEIL(x)` | `CEILING(x)` |
| 向下取整 | `FLOOR(x)` | `FLOOR(x)` |
| 四舍五入 | `ROUND(x, d)` | `ROUND(x, d)` |
| 截断（不四舍五入） | `TRUNCATE(x, d)` | `ROUND(x, d, 1)` |
| 取余 | `MOD(a, b)` 或 `a % b` | `a % b` |
| 随机数 | `RAND()` | `RAND()` |

只记一处差别：**`TRUNCATE` 是 MySQL 的截断函数**（函数）——注意它与同名的 `TRUNCATE TABLE` 语句毫无关系，只是重名。T-SQL 里截断小数要用 `ROUND(x, d, 1)` 这个怪异的三参数形式。

另一个提醒：`ORDER BY RAND() LIMIT 10` 取随机 10 条虽然好用，但它会给**每一行**算一次随机数再排序，10 万行的表就是 10 万次随机 + 全表排序。数据量一大必须换方案（第 12 章）。

==二：使用格式==

```sql
SELECT CEIL(1.1), FLOOR(1.9), ROUND(1.567, 2), TRUNCATE(1.567, 2), MOD(10, 3);
-- 2, 1, 1.57, 1.56, 1
```

==四：总结归纳==

- 三条：`CEIL` 不叫 `CEILING`；小数截断用 `TRUNCATE(x,d)`；`RAND()` 别在大表上排序。
- 记忆锚：和 T-SQL 只差一个函数名的字母。
- 自测：`TRUNCATE(1.999, 2)` 返回 1.99 还是 2.00？
