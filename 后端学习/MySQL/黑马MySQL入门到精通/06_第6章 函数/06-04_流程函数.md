# 流程函数

> 来源：P30《30. 基础-函数-流程函数》 · 档位 B 部分重叠
> 与我已知的关系：`CASE WHEN` 完全一样；**`IIF` 改名成 `IF`，`ISNULL` 改名成 `IFNULL`，`ISNULL` 在 MySQL 里是另一个函数**

==一：意义与概念==

在 SQL 里写条件分支，把判断结果直接算成列。四个函数：

| 需求 | MySQL | T-SQL | 说明 |
|---|---|---|---|
| 二选一 | `IF(条件, 真值, 假值)` | `IIF(条件, 真值, 假值)` | 只差一个字母 |
| 空值兜底 | `IFNULL(a, 兜底值)` | `ISNULL(a, 兜底值)` | **名字最容易混淆的一对** |
| 多列取第一个非空 | `COALESCE(a, b, c)` | `COALESCE` | 两边同名，标准 SQL |
| 多分支 | `CASE WHEN ... THEN ... END` | 同名 | 完全一致 |
| 空值置空 | `NULLIF(a, b)` | `NULLIF` | 相等则返回 NULL，用于避免除零 |

**必须点破的陷阱**：MySQL 里也有一个叫 `ISNULL()` 的函数，但它**只返回 0/1 表示是否为空**，不是"空值兜底"。`ISNULL(a, b)` 写两个参数在 MySQL 直接报参数个数错误。T-SQL 的 `ISNULL(a,b)` 到 MySQL 必须改写成 `IFNULL(a,b)`。

另一个概念点：`CASE` 有两种写法，语义不同：

- **简单 CASE**：`CASE 列 WHEN 值 THEN 结果 ...` —— 只能做等值比较。
- **搜索 CASE**：`CASE WHEN 条件 THEN 结果 ...` —— 能做任意条件（区间、组合）。

`CASE` 走的是**短路求值**：从上到下，命中第一个 `WHEN` 就停。没写 `ELSE` 时返回 `NULL`（不是报错，也不是 0）。

==二：使用格式==

```sql
IF(条件, 值1, 值2)
IFNULL(值, 兜底值)
NULLIF(值1, 值2)
CASE [列] WHEN 值 THEN 结果 ... [ELSE 兜底] END
CASE WHEN 条件 THEN 结果 ... [ELSE 兜底] END
```

==三：代码实践==

```sql
-- 二选一
SELECT name, IF(gender = 1, '男', '女') AS 性别 FROM emp;

-- 空值兜底：奖金为空显示 0
SELECT name, IFNULL(bonus, 0) AS 奖金 FROM emp;

-- 多分支：成绩分级（搜索 CASE）
SELECT name, score,
       CASE WHEN score >= 90 THEN '优秀'
            WHEN score >= 60 THEN '及格'
            ELSE '不及格' END AS 等级
FROM exam;

-- 简单 CASE：状态码转文字
SELECT order_no,
       CASE status WHEN 1 THEN '待付款'
                   WHEN 2 THEN '已发货'
                   ELSE '未知' END AS 状态
FROM `order`;

-- 避免除零：总数为 0 时返回 NULL 而不是报错
SELECT SUM(a) / NULLIF(SUM(b), 0) FROM stat;
```

反例：

```sql
SELECT ISNULL(bonus, 0) FROM emp;
-- ERROR 1582: Incorrect parameter count in the call to native function 'ISNULL'
-- 因为是"是否为空"的判断函数，只收一个参数
```

==四：总结归纳==

- 三条：`IF` 对应 `IIF`；`IFNULL` 对应 `ISNULL`（而 MySQL 的 `ISNULL()` 是判断空值，不是兜底）；`CASE` 两种写法按需选。
- 记忆锚：加了个 `F`（IF→IFNULL）就是"空值兜底"，没加就是"二选一"。
