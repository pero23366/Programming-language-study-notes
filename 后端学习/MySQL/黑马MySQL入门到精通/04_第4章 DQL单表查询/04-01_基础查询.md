# DQL 基础查询

> 来源：P15《15. 基础-SQL-DQL-基础查询》 · 档位 A 几乎重叠
> 与我已知的关系：`SELECT` 列、别名、`DISTINCT` 与 T-SQL 完全一致

==一：意义与概念==

两种查询形态：查**列**（投影）和查**行**（筛选，下一篇讲）。本篇只涉及投影部分，没有新知识，只有三个细节确认：

1. 别名 `AS` 可省，但**中文别名建议用引号包**：`SELECT name AS '姓名'`。
2. `DISTINCT` 作用于**整行去重**（多列时是组合去重），不是只对第一列生效。
3. `SELECT 1+1;` 可以不写 `FROM`——T-SQL 里也能，两边一样，常用来快速验连接。

唯一要改的习惯：字符串拼接用 `CONCAT()`，**不能用 `+`**。MySQL 里 `'1' + '2'` 的结果是 `3`（隐式转数字相加），不是 `'12'`。这个坑在第 6 章函数里展开。

==二：使用格式==

```sql
SELECT 列1, 列2 FROM 表名;
SELECT 列1 AS 别名, 列2 别名 FROM 表名;
SELECT DISTINCT 列1, 列2 FROM 表名;
SELECT * FROM 表名;        -- 生产查询尽量别用，回表代价大
```

==四：总结归纳==

- 三条：别名可省 `AS`；`DISTINCT` 按整行去重；拼接字符串只用 `CONCAT`。
- 记忆锚：这一节等于 T-SQL 的开胃菜，闭着眼写。
- 自测：`SELECT '1' + '2';` 返回什么？
