# DQL 聚合函数

> 来源：P17《17. 基础-SQL-DQL-聚合函数》 · 档位 A 几乎重叠
> 与我已知的关系：`COUNT` / `SUM` / `AVG` / `MAX` / `MIN` 五个函数，行为与 T-SQL 一致

==一：意义与概念==

把多行压成一行。五个函数都不用重学，只需确认两件事：

1. **`NULL` 不参与计算**：`SUM` 忽略 NULL、`AVG` 的分母不含 NULL 行。所以 `AVG(salary)` 在有 NULL 时**不等于** `SUM(salary)/COUNT(*)`——这是对账时最常见的"数对不上"。
2. **`COUNT(*)` 与 `COUNT(列)` 不同**：前者数行数（含全 NULL 行），后者只数该列非 NULL 的行。`COUNT(1)` 与 `COUNT(*)` 在 InnoDB 里优化后等价。

T-SQL 的 `COUNT_BIG` 在 MySQL 里没有，直接用 `COUNT`（返回 `BIGINT`，本来就大）。

==二：使用格式==

```sql
SELECT COUNT(*) FROM emp;
SELECT COUNT(id_card) FROM emp;      -- 只数 id_card 非空的行
SELECT SUM(salary), AVG(salary), MAX(salary), MIN(salary) FROM emp;
```

==四：总结归纳==

- 三条：NULL 不参与任何聚合；`COUNT(*)` 数行、`COUNT(列)` 数非空；没有 `COUNT_BIG`。
- 记忆锚：聚合函数是"把一列折成一个数"，NULL 是隐形的，不占分母。
- 自测：表里 10 行，`salary` 有 2 行是 NULL，`AVG(salary)` 的分母是几？
