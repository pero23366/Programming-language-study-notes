```csharp
// 普通方法：有返回类型 + 方法名
public void Eat()          // void 是返回类型，Eat 是方法名
{
}

// 构造函数：没有返回类型 + 名字必须等于类名
public Animal(string name) // 没有返回类型，名字就是 Animal,
{
}
```
==构造函数的特点是：==

- **没有返回类型**（连 `void` 都不写）。
    
- **名字必须和类名一模一样**。

==补充==
***普通函数实例化时候不可以传参数***
用构造函数的意义
**实例化时候可以直接传参数，**
**避免忘记初始化**
