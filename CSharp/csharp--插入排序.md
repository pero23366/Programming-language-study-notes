==一：概念==

**插入排序是什么？**

插入排序是一种简单直观的排序算法，它的工作原理就像**整理手中的扑克牌**[](https://zhuanlan.zhihu.com/p/450256958#0)。你将数组分为**已排序区**和**未排序区**，每次从未排序区取出第一个元素，在已排序区中从后向前扫描，找到合适的位置插入进去[](https://cloud.tencent.cn/developer/article/2456678?policyId=1003#1)。

**核心思想：**

排序开始时，默认第一个元素已经在已排序区，其余所有元素在未排序区。然后不断将未排序区的第一个元素，插入到已排序区的正确位置，直到未排序区清空[](https://zhuanlan.zhihu.com/p/450256958#0)。

**打个比方：**

你手里有一把牌，你一张一张地摸。每摸到一张新牌，就把它插到手里已排好序的牌中的正确位置。插入排序就是这个过程。

**关键特点：**

|特点|说明|
|---|---|
|**时间复杂度**|平均和最坏情况 O(n²)，最好情况 O(n)（数组已有序）[](https://cloud.tencent.cn/developer/article/2456678?policyId=1003#1)|
|**空间复杂度**|O(1)，只需要一个临时变量[](https://cloud.tencent.cn/developer/article/2456678?policyId=1003#1)|
|**稳定性**|稳定排序|
|**适用场景**|小规模数据排序，效率较高[](https://www.e-com-net.com/article/1753339586261565440.htm)|

**和冒泡排序的区别：**

冒泡排序每一轮都要和剩余所有元素比较，而插入排序在比较过程中，**一旦条件不满足就马上停止**，所以用 `while` 循环更合适[](https://zhuanlan.zhihu.com/p/450256958#0)。

==二：格式==

**基本逻辑：**

```csharp

// 外层循环：从第二个元素开始，依次取出未排序区的元素
for (int i = 1; i < arr.Length; i++)
{
    int key = arr[i];        // 取出未排序区的第一个元素
    int j = i - 1;           // 已排序区最后一个元素的索引
    // 内层循环：在已排序区中从后向前扫描，找到插入位置
    while (j >= 0 && arr[j] > key)
    {
        arr[j + 1] = arr[j]; // 已排序区元素往后移动一位
        j--;                  // 继续往前比较
    }
    arr[j + 1] = key;        // 插入到正确位置
}
```

**关键点：**

|要点|说明|
|---|---|
|外层循环从 `i = 1` 开始|默认第一个元素在已排序区|
|`key` 保存当前要插入的元素|防止被覆盖|
|内层用 `while`|条件不满足时立即停止|
|插入位置是 `j + 1`|循环停止时，插入位置在停止索引的下一个|
==三：代码==
### 升序排序

```csharp

using System;
class Program
{
    static void Main()
    {
        int[] arr = { 9, 5, 1, 4, 3 };
        int n = arr.Length;
        // 插入排序
        for (int i = 1; i < n; i++)
        {
            int key = arr[i];    // 取出未排序区的第一个元素
            int j = i - 1;       // 已排序区的最后一个元素
            // 从后向前扫描，找到插入位置
            while (j >= 0 && arr[j] > key)
            {
                arr[j + 1] = arr[j];  // 已排序区元素后移一位
                j--;
            }
            arr[j + 1] = key;    // 插入到正确位置
        }
        // 输出结果
        Console.WriteLine("排序后：");
        foreach (int value in arr)
        {
            Console.Write(value + " ");
        }
    }
}
```

**输出：** `1 3 4 5 9`

### 执行过程拆解（以 `{9, 5, 1, 4, 3}` 为例）

```text

初始：9 | 5, 1, 4, 3   （| 左边是已排序区，右边是未排序区）
第1轮：取出 5，和 9 比较，5 < 9 → 9 后移，5 插入到位置 0
结果：5, 9 | 1, 4, 3
第2轮：取出 1，和 9 比较，1 < 9 → 9 后移；和 5 比较，1 < 5 → 5 后移；插入到位置 0
结果：1, 5, 9 | 4, 3
第3轮：取出 4，和 9 比较，4 < 9 → 9 后移；和 5 比较，4 < 5 → 5 后移；和 1 比较，4 > 1 → 停止；插入到位置 1
结果：1, 4, 5, 9 | 3
第4轮：取出 3，和 9 比较，3 < 9 → 9 后移；和 5 比较，3 < 5 → 5 后移；和 4 比较，3 < 4 → 4 后移；和 1 比较，3 > 1 → 停止；插入到位置 1
结果：1, 3, 4, 5, 9

```
### 降序排序

**只需把 `arr[j] > key` 改成 `arr[j] < key`**[](https://zhuanlan.zhihu.com/p/450256958#0)。

```csharp

while (j >= 0 && arr[j] < key)  // 已排序数小于未排序数
{
    arr[j + 1] = arr[j];
    j--;
}
arr[j + 1] = key;

```
### 用 `for` 循环实现内层

`while` 也可以用 `for` 替代[](https://www.e-com-net.com/article/1753339586261565440.htm)：

```csharp

for (int i = 1; i < arr.Length; i++)
{
    int temp = arr[i];
    for (int j = i - 1; j >= 0; j--)
    {
        if (arr[j] > temp)
        {
            arr[j + 1] = arr[j];
            arr[j] = temp;
        }
        else break;
    }
}
```

==四：总结==

### 核心要点

|要点|说明|
|---|---|
|**概念**|分已排序区和未排序区，逐个插入|
|**时间复杂度**|平均 O(n²)，最好 O(n)|
|**空间复杂度**|O(1)|
|**稳定性**|稳定排序|
|**核心操作**|比较 + 后移 + 插入|

### 关键逻辑

|问题|答案|
|---|---|
|外层循环从几开始？|从 `i = 1` 开始，默认第一个元素已排序|
|为什么用 `while`？|条件不满足就停止，不需要继续比较|
|插入位置在哪？|`j + 1`（循环停止时索引的下一个）|
|怎么改成降序？|把 `>` 改成 `<`|

### 和冒泡排序的区别

|冒泡排序|插入排序|
|---|---|---|
|比较方式|每一轮和剩余所有元素比较|从后向前扫描，条件不满足就停|
|适合循环|`for`|`while`|
|最好情况|O(n²)|**O(n)**（已有序）|

### 一句话总结

> **插入排序就像整理扑克牌——手里始终握着一把已排好序的牌，每摸到一张新牌，就从后往前找位置插进去。**
