==一：客观总结==
```csharp
1. **静态成员属于类，不属于对象**  
    用 `static` 修饰，全程序只有一份，通过 `类名.成员` 访问，不需要 `new`。
    
2. **你早就用过静态成员**  
    `Console.WriteLine()`、`Math.Abs()`、`static void Main()` 都是静态的。
    
3. **自定义静态成员也一样**
    
    csharp
    
    class MyTool
    {
        public static int Count;
        public static void Hello() { }
    }
    
    使用 `MyTool.Count`、`MyTool.Hello()`。
    
4. **为什么能直接点出来**  
    因为静态成员存在静态存储区，==位置固定==，和具体对象无关。
    
5. **静态函数中不能直接用非静态成员**  
    静态方法没有 `this`，不知道去堆上的哪个对象找实例字段。
    
6. **非静态函数可以使用静态成员**  
    实例方法有 `this`，同时也能访问全程序共享的静态成员。
    
7. **作用**  
    工具方法、共享数据、全局配置适合用静态。  
    每个对象需要独立一份数据时，用实例成员。
    
8. **常量和静态变量**  
    `const` 是编译时常量，声明时赋值，之后不能改。  
    `static` 变量在静态存储区，全程序共用，可以修改。
    
9. **内存角度**  
    栈：局部变量、方法参数。  
    堆：`new` 出来的对象、实例字段。  
    静态存储区：静态字段、静态方法、类型信息。  
    `Main` 必须是静态的，因为程序启动时还没有任何对象。
```
==二：比喻==
```csharp
- **静态成员** = 公司公告栏、公共账户、公共设施  
    所有员工共用，不需要先招聘某个员工，直接找公司就行。
    
- **实例成员** = 每个员工的私人工位、私人抽屉  
    每个员工各有一份，必须知道是哪个员工。
    
- `Console.WriteLine()` = 公共服务中心的电话  
    不用先创建对象，直接打。
    
- `Math.Abs()` = 公司大厅里的公共计算器  
    谁都能用，不属于某个员工。
    
- `Main()` = 公司每天开门第一件事  
    由公司本身执行，不需要先有员工。
    
- **静态方法不能用非静态成员** = 前台不知道找哪个员工  
    因为没有具体的人。
    
- **非静态方法可以用静态成员** = 员工可以看公司公告栏  
    个人能访问公共信息。
    
- **栈** = 临时便签、工作台  
    方法一结束就收走。
    
- **堆** = 个人储物柜、仓库  
    每个对象自己的东西放这里。
    
- **静态存储区** = 公司大厅公告栏、公共仓库  
    全公司共用，一直存在。
    
- `const` = 刻在石碑上的字  
    不能改。
    
- `static` 变量 = 白板上的数字  
    全公司共用，可以擦掉重写。
```
==三：总结==
****需要全程序共用、不用创建对象，就用 `static`；  
需要每个对象各自一份，就用普通实例成员。****
