==一：定义==
```csharp
**静态成员**  
用 `static` 修饰的字段或方法。  
属于**类**，不属于对象。全程序只有一份，用 `类名.成员` 访问。

**静态类**  
用 `static` 修饰的类。  
不能 `new`，里面只能有静态成员。

**静态构造函数**  
写法是 `static 类名()`。  
不能有访问修饰符，不能有参数，不能直接调用。  
第一次使用类之前自动执行，只执行一次，用来初始化静态字段。

**实例成员**  
不用 `static` 修饰的字段或方法。  
属于对象，每个对象一份，用 `对象名.成员` 访问。
```
==二：作用==
```csharp
**静态成员**  
用来放工具方法、全局共享数据、计数器、配置等。  
不需要创建对象，直接类名访问。

**静态类**  
用来装公共工具方法，比如 `Math`、`Console`。  
不用 `new`，直接 `类名.方法()`。

**静态构造函数**  
用来在第一次使用类之前，把静态数据准备好。  
只做一次，之后不再执行。

**普通类**  
也可以有静态成员，也可以全程序共享。  
但普通类还能 `new` 对象，实例成员每个对象一份。
```
==三：例子==
```csharp
static class MyTool
{
    public static int Count;

    static MyTool()
    {
        Count = 10;
        Console.WriteLine("静态构造函数执行");
    }

    public static void Add()
    {
        Count++;
        Console.WriteLine("Add: " + Count);
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine("开始");
         //在调用 Add() 之前，
 //CLR 会自动先执行静态构造函数：
        MyTool.Add();
        MyTool.Add();
        Console.WriteLine("结束");
    }
}
```
==四：易错==
```csharp
1. **静态类不能 `new`**  
    `MyTool t = new MyTool();` 是错的。
    
2. **静态构造函数不能写访问修饰符**  
    不能写 `public static MyTool()`，只能写 `static MyTool()`。
    
3. **静态构造函数不能有参数，不能重载，不能直接调用**  
    它由 CLR 自动调用。
    
4. **静态构造函数只执行一次**  
    不是每次调用方法都执行。
    
5. **静态方法里不能直接用实例成员**  
    因为静态方法没有 `this`，不知道找哪个对象。
    
6. **非静态方法可以用静态成员**  
    实例方法有 `this`，同时也能访问全程序共享的静态成员。
    
7. **静态字段全程序一份**  
    不是每个对象一份。每个对象一份的是实例字段。
    
8. **`static` 和 `public` 是两回事**  
    `static` 管归属：属于类还是对象。  
    `public` 管权限：外面能不能访问。
    
9. **`const` 和 `static` 不一样**  
    `const` 是常量，不能改。  
    `static` 变量在静态存储区，可以改。
    
10. **命名空间只是文件夹**  
    里面放类、结构体、接口、枚举、委托，不能直接放变量和方法。
```
%%CLR 是 .NET 平台的**运行时环境**。%%
```csharp
1. **加载程序集**  
    你的 `.dll`、`.exe` 由 CLR 加载。
    
2. **把 IL 编译成机器码**  
    这叫 JIT（即时编译），让 CPU 能执行。
    
3. **管理内存**  
    负责创建对象、回收垃圾（GC）。
    
4. **类型安全检查**  
    防止乱转类型、乱访问内存。
    
5. **异常处理**  
    程序出错时，CLR 负责抛出和处理异常。
    
6. **线程管理**  
    管理多线程执行。
    
7. **自动调用静态构造函数**  
    你之前问的“静态构造函数为什么自动执行”，就是 CLR 在第一次使用类时帮你调用的。
    
    
    你写 C# 代码
    ↓
编译器编译成 IL（中间代码）
    ↓
生成程序集 .exe / .dll
    ↓
运行时，CLR 加载程序集
    ↓
CLR 把 IL 编译成机器码
    ↓
CPU 执行
```
