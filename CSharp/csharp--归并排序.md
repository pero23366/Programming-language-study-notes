==一：概念==

**归并排序是什么？**

归并排序是一种**分治法**的典型应用。它的核心思想是**“先分后合”**：先把数组不断对半拆分，直到每个子数组只剩一个元素（一个元素天然有序），然后再把这些有序的子数组**两两合并**，最终得到一个完整的有序数组。

**为什么需要它？**

回顾一下：

- **插入排序**：平均 O(n²)，适合小规模数据
    
- **希尔排序**：平均约 O(n^1.3)，是插入排序的改进
    
- **归并排序**：**无论最好、最坏还是平均，时间复杂度都是 O(n log n)**
    

**这是归并排序最大的优势——性能非常稳定，不受输入数据影响。**

**核心思想：分治法（Divide and Conquer）**

```text

分（Divide）：把数组从中间切成两半，递归地对两半分别排序
治（Conquer）：把两个已经有序的子数组合并成一个有序数组
```

**打个比方：**

你和朋友一起整理两摞已经排好序的扑克牌。你们各自出一张牌，比较谁的小，小的放前面，然后继续出下一张。这样合并出来的整摞牌就是有序的。归并排序就是**先把牌分成单张，再两两合并，逐步合并成完整的一摞**。

**关键特点：**

|特点|说明|
|---|---|
|**时间复杂度**|最好、最坏、平均都是 **O(n log n)**|
|**空间复杂度**|**O(n)**，需要额外数组来合并|
|**稳定性**|**稳定排序**（合并时相等元素保留左半优先）|
|**适用场景**|大数据量排序，要求稳定性的场景|
==二：格式==

**归并排序分为两个部分：**

**1. 分（递归拆分）：**

```csharp

void MergeSort(int[] arr, int left, int right)
{
    if (left >= right) return;           // 只剩一个元素，天然有序
    int mid = (left + right) / 2;        // 从中间切开
    MergeSort(arr, left, mid);            // 递归排序左半
    MergeSort(arr, mid + 1, right);       // 递归排序右半
    Merge(arr, left, mid, right);         // 合并两个有序子数组
}
```

**2. 合（合并两个有序子数组）：**

```csharp

void Merge(int[] arr, int left, int mid, int right)
{
    int[] temp = new int[right - left + 1];  // 临时数组
    int i = left, j = mid + 1, k = 0;        // 三个指针
    while (i <= mid && j <= right)           // 两边都还有元素
    {
        if (arr[i] <= arr[j])                // 左边小，取左边（保证稳定）
            temp[k++] = arr[i++];
        else
            temp[k++] = arr[j++];            // 右边小，取右边
    }
    while (i <= mid)  temp[k++] = arr[i++];  // 左边剩余
    while (j <= right) temp[k++] = arr[j++]; // 右边剩余
    // 把临时数组复制回原数组
    for (int m = 0; m < temp.Length; m++)
        arr[left + m] = temp[m];
}
```

**关键点：**

|要点|说明|
|---|---|
|**递归终止条件**|`left >= right`，只剩一个元素|
|**中点计算**|`mid = (left + right) / 2`|
|**合并条件**|`arr[i] <= arr[j]` 用 `<=` 保证稳定性|
|**临时数组**|合并时需要额外空间|
==三：代码==

### 完整示例

```csharp

using System;
class Program
{
    static void Main()
    {
        int[] arr = { 38, 27, 43, 3, 9, 82, 10 };
        MergeSort(arr, 0, arr.Length - 1);
        Console.WriteLine("排序后：");
        foreach (int value in arr)
            Console.Write(value + " ");
        // 输出：3 9 10 27 38 43 82
    }
    static void MergeSort(int[] arr, int left, int right)
    {
        if (left >= right) return;           // 递归终止
        int mid = (left + right) / 2;        // 从中间切开
        MergeSort(arr, left, mid);            // 排序左半
        MergeSort(arr, mid + 1, right);       // 排序右半
        Merge(arr, left, mid, right);         // 合并
    }
    static void Merge(int[] arr, int left, int mid, int right)
    {
        int[] temp = new int[right - left + 1];
        int i = left, j = mid + 1, k = 0;
        while (i <= mid && j <= right)
        {
            if (arr[i] <= arr[j])
                temp[k++] = arr[i++];
            else
                temp[k++] = arr[j++];
        }
        while (i <= mid)  temp[k++] = arr[i++];
        while (j <= right) temp[k++] = arr[j++];
        for (int m = 0; m < temp.Length; m++)
            arr[left + m] = temp[m];
    }
}

```
### 执行过程拆解（以 `{38, 27, 43, 3, 9, 82, 10}` 为例）

**第一步：分（递归拆分）**

```text

{38, 27, 43, 3, 9, 82, 10}
    ↓ 从中间切
{38, 27, 43}     {3, 9, 82, 10}
    ↓ 继续切
{38} {27, 43}    {3, 9} {82, 10}
    ↓
{38} {27} {43}   {3} {9} {82} {10}   ← 每个子数组只剩一个元素

```
**第二步：合（两两合并）**

```text

{27} + {43} → {27, 43}          {3} + {9} → {3, 9}      {82} + {10} → {10, 82}
{38} + {27, 43} → {27, 38, 43}  {3, 9} + {10, 82} → {3, 9, 10, 82}
{27, 38, 43} + {3, 9, 10, 82} → {3, 9, 10, 27, 38, 43, 82}
```

**合并的细节（`{27, 38, 43}` 和 `{3, 9, 10, 82}`）：**

```text

i=0(27), j=3(3):  27 > 3  → 取3   temp=[3]
i=0(27), j=4(9):  27 > 9  → 取9   temp=[3,9]
i=0(27), j=5(10): 27 > 10 → 取10  temp=[3,9,10]
i=0(27), j=6(82): 27 < 82 → 取27  temp=[3,9,10,27]
i=1(38), j=6(82): 38 < 82 → 取38  temp=[3,9,10,27,38]
i=2(43), j=6(82): 43 < 82 → 取43  temp=[3,9,10,27,38,43]
i超出左半范围 → 把右边剩余的82复制过来
最终：temp = [3, 9, 10, 27, 38, 43, 82]
```

### 降序排序

==四：总结==

|要点|说明|
|---|---|
|**概念**|分治法：先拆分，再合并|
|**时间复杂度**|最好、最坏、平均都是 O(n log n)|
|**空间复杂度**|O(n)，需要临时数组|
|**稳定性**|**稳定排序**|
|**核心操作**|递归拆分 + 合并有序子数组|

### 关键逻辑

|问题|答案|
|---|---|
|递归终止条件？|`left >= right`（只剩一个元素）|
|怎么拆分？|`mid = (left + right) / 2`|
|合并时怎么比较？|两边各出一个，取小的放前面|
|为什么稳定？|用 `<=` 比较，相等时优先取左边|
|怎么改降序？|把 `<=` 改成 `>=`|

### 和其他排序算法的对比

| 稳定性   | 稳定    | 不稳定        | **稳定**         |
| ----- | ----- | ---------- | -------------- |
| 插入排序  | 希尔排序  | 归并排序       |                |
| 时间复杂度 | O(n²) | 约 O(n^1.3) | **O(n log n)** |
| 空间复杂度 | O(1)  | O(1)       | O(n)           |
| 最好情况  | O(n)  | O(n)       | O(n log n)     |

**希尔排序（原地调整）：**
```text

初始：{9, 5, 1, 4, 3, 8, 2, 7, 6}
gap=4：按间隔4分组，组内调整
       {3, 5, 1, 4, 8, 2, 7, 6, 9}
gap=2：按间隔2分组，组内调整
       {1, 2, 3, 4, 7, 5, 8, 6, 9}
gap=1：整体插入排序（已经基本有序，很快）
       {1, 2, 3, 4, 5, 6, 7, 8, 9}
始终是同一个数组，没有拆开过。
```

**归并排序（拆开再拼）：**

```text

初始：{38, 27, 43, 3, 9, 82, 10}
分：
  {38, 27, 43}  {3, 9, 82, 10}
  {38} {27, 43}  {3, 9} {82, 10}
  {38} {27} {43}  {3} {9} {82} {10}   ← 拆到不能再拆
合：
  {27} + {43} → {27, 43}
  {38} + {27, 43} → {27, 38, 43}
  {3} + {9} → {3, 9}
  {82} + {10} → {10, 82}
  {3, 9} + {10, 82} → {3, 9, 10, 82}
  {27, 38, 43} + {3, 9, 10, 82} → {3, 9, 10, 27, 38, 43, 82}
先拆开，再拼起来。
```
