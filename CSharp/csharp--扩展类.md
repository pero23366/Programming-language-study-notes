==一：概念==
```csharp
你可以把扩展方法想象成一种 **“给别人的东西贴标签”** 的能力。

比如，你有一个别人写好的 `string` 类，你不能去改它的源代码。但你想加一个功能：“判断这个字符串是不是空的”。扩展方法就允许你在**不修改 `string` 类源代码**的情况下，像给手机贴膜一样，给它“贴”上一个新方法 `IsEmpty()`。

这个概念的核心是：

- **不修改原类型**：你不用去改那个类的源代码。
    
- **不继承**：你不需要创建一个新的子类。
    
- **像自带方法一样调用**：写代码时，感觉就像这个类型本来就有这个方法一样。
```
==二：格式==
```csharp
// 1. 必须是静态类
public static class 你的扩展类名
{
    // 2. 必须是静态方法；3. 第一个参数用 this 修饰，表示要扩展的类型
    public static 返回值类型 你的方法名(this 要扩展的类型 参数名, 其他参数...)
    {
        // 方法体
    }
}
```
